# Caro Matchmaking Server

Web server mini cho game caro, co hang cho ghep cap tu dong qua WebSocket.

## Chay local

```bash
npm install
npm start
```

Mo `http://localhost:3000` trong nhieu tab/trinh duyet de test ghep cap.

## Luong hoat dong

- Nguoi choi bam `San sang` se vao hang cho.
- Nguoi choi thu 2 vao hang cho se duoc ghep ngay voi nguoi thu 1.
- Nguoi choi thu 3 se phai doi nguoi thu 4.
- Ket thuc tran thi ca 2 ben roi ve trang thai idle va chi vao hang cho lai khi bam `San sang`.
